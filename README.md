# Oil Field Python Projects

Petroleum Engineering simulations built 100% on Android with Pydroid 3.

## What’s inside:
- **field_dashboard.py** - Well production bar chart
- **mbe.py** - Material Balance Equation for OOIP
- **mbe_forecast.py** - Predict oil left in reservoir  
- **decline.py** - Well decline curve analysis
- **oil_company_app.py** - Full well dashboard
- **final_field_report.py** - Full report with 3 graphs + $2.5B reserves
